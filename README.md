# 有解 · 问题解决实战手册

> **遇事不慌，拆解有方，落地有章。**
> 一套适合中国人的问题解决方法论 + 工具箱 + 案例库 + 场景手册 + 资料库：
> **全面、去重、简洁、可操作**。

---

## 这是什么

人生在世，问题不断：工作卡壳、选择困难、拖延内耗、关系紧张……
多数人不是不够努力，而是缺一套**解决问题的通用流程**——出了事全靠本能，同样的坑反复踩。

本仓库综合《有解》《麦肯锡方法》《金字塔原理》《系统之美》《高效能人士的七个习惯》《孙子兵法》等中外经典方法论，与 PDCA、MECE、5Why、KT、8D 等实战工具**去重整合**成一套拿来即用的体系：

- **一套流程**：有解七步法 —— 任何问题都走这七步（配贯穿案例）
- **一个工具箱**：45 个工具按"澄清 / 拆解 / 归因 / 决策 / 创新 / 执行 / 项目 / 复盘 / 沟通"九类速查
- **一本案例集**：10 个完整实战案例，七步从头走到尾，含具体数字和踩坑
- **一本场景手册**：职场 / 学习 / 生活 / 关系 / 情绪，28 个高频问题速查（每个带实例）
- **一个资料库**：50+ 本书籍资料、经典框架出处、7 天 / 30 天 / 90 天学习路径
- **一组清单模板**：急救卡、问题画布、决策矩阵、A3、8D、风险登记表、复盘模板

## 适合谁

- 遇到问题容易**慌、拖、绕**，想要一套稳定流程的人
- 想系统提升**解决问题能力**（职场最硬的软实力）的人
- 方法论书看了一堆，但**用不起来**的人
- 想给团队建一套**共同问题语言**的管理者

## 核心理念（5 句话）

1. **问题 = 期望 − 现状**：说清楚差距，问题就解决了一半
2. **先处理情绪，再处理问题**：带着恐慌做决策，等于用情绪给未来挖坑
3. **先有框架，再填细节**：一上来就找办法，是最常见的浪费
4. **先完成，再完美**：方案 60 分就先跑起来，迭代比空想值钱
5. **复盘才能复利**：不复盘的经历只是经历，复盘过的才是资产
