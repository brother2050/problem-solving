# 有解 · 问题解决实战手册

> **遇事不慌，拆解有方，落地有章。**
> 一套适合中国人的问题解决方法论 + 工具箱 + 案例库 + 场景手册 + 资料库：
> **全面、去重、简洁、可操作**。

---

## 这是什么

人生在世，问题不断：工作卡壳、选择困难、拖延内耗、关系紧张……
多数人不是不够努力，而是缺一套**解决问题的通用流程**——出了事全靠本能，同样的坑反复踩。

本仓库综合《有解》《麦肯锡方法》《金字塔原理》《系统之美》《高效能人士的七个习惯》《孙子兵法》等中外经典方法论，与 PDCA、MECE、5Why、KT、8D 等实战工具**去重整合**成一套拿来即用的体系：

- **一套流程**：有解七步法 —— 任何问题都走这七步（配贯穿案例）
- **一套分类**：问题三分法（恢复原状 / 防范潜在 / 追求理想）+ 可控度 + 规模 —— 先定性，再解题
- **一套原理**：30 条核心理论（实证出处 + 实操动作 + 常见误区）—— 知道为什么有效，才能灵活变通
- **一套方案**：8 条端到端处理流程（事故/冲突/决策/目标/拖延/新业务/团队/低谷）—— 从触发到闭环，每步标清交接物
- **一个工具箱**：51 个工具按"澄清 / 拆解 / 归因 / 决策 / 创新 / 执行 / 项目 / 复盘 / 沟通 / 思维校准"十类速查，每个工具标注出处
- **一本案例集**：10 个实战案例 + 3 个真实公开案例（丰田、NASA），七步从头走到尾，含具体数字、踩坑与证据链
- **一本场景手册**：职场 / 学习 / 生活 / 关系 / 情绪 / 管理 / 危机，35 个高频问题速查（每个带实例）
- **一个资料库**：60+ 本书籍资料（含可核查书目信息）、26 个框架出处考证、26 篇实证文献索引、证据链对照表、6 个真实事件延伸线索、7/30/90 天学习路径
- **一组清单模板**：急救卡、问题画布、决策矩阵、A3、8D、风险登记表、复盘模板 + 干系人地图、事实/观点分家表、MVP 画布、实施意图卡、时间日志

## 核心理念（5 句话）

1. **问题 = 期望 − 现状**：说清楚差距，问题就解决了一半
2. **先处理情绪，再处理问题**：带着恐慌做决策，等于用情绪给未来挖坑
3. **先有框架，再填细节**：一上来就找办法，是最常见的浪费
4. **先完成，再完美**：方案 60 分就先跑起来，迭代比空想值钱
5. **复盘才能复利**：不复盘的经历只是经历，复盘过的才是资产

## 全库关联图（前后关系）

```
                ┌─ THEORY 理论（为什么有效，30 条实证）
                │
遇到问题 → TAXONOMY 分类 → METHOD 七步 → TOOLKIT 工具 → CHECKLIST 模板 → 行动
                │              │              │                        │
                │              └─ WORKFLOWS 8 条端到端 SOP（怎么串起来）
                │                             │
                ├─ PLAYBOOK 场景（35 个对号入座）      ├─ CASES 案例（10 实战 + 3 真实）
                └─ MINDSET 心智（状态底盘）            └─ SOURCES 资料（出处 + 证据链 + 文献）
```

**读写闭环**：SOURCES（输入）→ THEORY+METHOD（内化）→ WORKFLOWS（执行）→ CHECKLIST（沉淀）→ 回到 SOURCES 验证出处。
**卡住急救**：任意环节卡壳 → [FAQ.md](FAQ.md) 按阶段查排错指南。
每篇文件尾部都有"配套"导航，任意入口都能走通全库。
